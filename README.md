# 🛍️ TrendyTots – Kids Clothing Shopping Website with Virtual Dress Preview System

## 📌 Project Overview

**TrendyTots** is a full-stack e-commerce web application designed to provide an interactive and convenient online shopping experience for children's clothing.

The application allows customers to explore clothing collections, view product details, manage shopping carts and wishlists, and experience an innovative Virtual Dress Preview System.

It also includes an administrative dashboard that enables product catalogue management and supports efficient website administration.

The project combines frontend development, backend programming, database management, and interactive shopping features into a single web application.

## ✨ Key Features

- **User-Friendly Homepage:** Attractive interface for browsing children's clothing collections.
- **Product Catalogue:** Browse products with images, descriptions, and pricing.
- **Product Details:** View individual product information.
- **Shopping Cart:** Add, manage, and review selected products.
- **Wishlist:** Save favourite products for future purchases.
- **Virtual Dress Preview:** Upload a child's photograph and select clothing items to experience a virtual outfit preview.
- **AI Assistant:** An interactive assistant page to enhance the shopping experience.
- **Admin Dashboard:** Manage products and maintain the product catalogue.

## 🏗️ System Architecture

The application follows a three-tier architecture:

1. **Presentation Layer:** HTML, CSS, and JavaScript provide the user interface.
2. **Application Layer:** Python Flask handles application logic, routing, and user requests.
3. **Data Layer:** SQLite stores and manages application data.

## ⚙️ Installation and Setup


**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/TrendyTots.git
```

**2. Navigate to the project directory**

```bash
cd TrendyTots
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the virtual environment**

Windows:

```bash
venv\Scripts\activate
```

**5. Install the dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the application**

```bash
python app.py
```

**7. Open in your browser**

```text
http://127.0.0.1:5000/
```
